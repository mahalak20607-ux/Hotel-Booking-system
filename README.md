# StaySmart – Hotel Booking Platform

StaySmart is a modern, responsive hotel booking website built using **HTML, CSS, Bootstrap, and JavaScript**.

### Features

* Hotel search by destination
* Real hotel and room images
* Hotel and room listings
* Booking form with confirmation
* Responsive design
* Customer testimonials
* Contact section

### Technologies

* HTML5
* CSS3
* Bootstrap 5
* JavaScript
* Font Awesome
